# Dungeon Scrawlers: Builds

Playable Windows builds of **Dungeon Scrawlers**, a first-person roguelite where a blacksmith forges guns, masters parkour, and outmaneuvers souls-style bosses, one drafted room at a time. Built in Unreal Engine 5.8 (Blueprint + GAS).

**Download:** see [Releases](https://github.com/BetterCodeGoblin/dungeon-scrawlers-builds/releases). Grab the latest `DungeonScrawlers_Win64.zip`, unzip, and run `DungeonScrawlers.exe`.

Status: pre-alpha. Expect rough edges.

## Requirements
- Windows 10/11, 64-bit
- DirectX 12 capable GPU
- If Windows SmartScreen warns about an unknown publisher, choose "More info" then "Run anyway" (the build is unsigned).
